# Mulheres que Servem

Landing page de apresentação da comunidade de Emily Bordignoni.

## Visualização

Abra `index.html` em um navegador. Para testar localmente com todos os recursos, sirva esta pasta por um servidor estático.

## Destinos configurados

- Compra: https://pay.kiwify.com.br/U4chBa2
- Devocional gratuito: https://drive.google.com/file/d/145AngcTvZ_COGaTWghNKTkECSkTPYaRQ/view
- Instagram: https://www.instagram.com/emilybordignoni/

Parâmetros UTM reconhecidos na URL da landing page são preservados ao encaminhar para o checkout.

## Publicação no GitHub Pages

Esta pasta já inclui a automação em `.github/workflows/pages.yml`. Coloque seu conteúdo na raiz de um repositório GitHub, use a branch `main` e, em **Settings → Pages → Build and deployment**, selecione **GitHub Actions**. Cada envio para a branch principal publicará o site automaticamente.
